# azure learning    

## Learning Path:

1. Learn about Azure -  Use Azure Fundamental learning path (AZ-900)

2. Learn about Fabric - Use Fabric Analytics Engineer learning path (DP-600)

3. Come up with business use cases and build project while learning - Build on Fabric  with the Trial version (60 days)

4. Document your work in GitHub. Use git to manage and push you documentation to GitHub - good way to learn how git works

5. Build portfolio page for your projects - You can find templates online

6. Include link to your project portfolio page on your CV or add to Linkedin.

7. It helps to also talk about your projects on Linkedin too.

8.  Keep attending the User Group for networking. Meet people . Talk to them. Anyone can have a job for you.
